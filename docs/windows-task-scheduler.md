# Windows 작업 스케줄러 등록 가이드

Boannews RSS → 하이웍스 digest 메일을 **매일 같은 시각에 한 번** 실행합니다.  
(GitHub Actions는 해외 IP라 하이웍스 SMTP와 맞지 않을 수 있어 **서버/PC에서 스케줄러만** 사용합니다.)

아래 경로 예시는 `D:\develop\hiworks-Ctrl` 입니다. 서버에 복사한 실제 폴더로 바꿔 주세요.

---

## 1단계: 폴더와 Python 준비 (1회)

### 1-1. 프로젝트가 서버에 있는지 확인

다음이 **같은 폴더** 안에 있어야 합니다.

- `src\main.py`
- `scripts\run_rss_mailer.ps1`
- `requirements.txt`
- `.env` (직접 만들고, GitHub에 올리지 않음)

### 1-2. PowerShell 열기

**시작** → `PowerShell` 검색 → **Windows PowerShell** 실행 (관리자 권한은 필수 아님).

### 1-3. 프로젝트 폴더로 이동

```powershell
cd D:\develop\hiworks-Ctrl
```

### 1-4. 가상환경 만들기

```powershell
python -m venv .venv
```

### 1-5. 패키지 설치

```powershell
.\.venv\Scripts\pip install -r requirements.txt
```

### 1-6. `.env` 확인

메모장으로 `.env`를 열어 다음이 채워져 있는지 봅니다.

- `HIWORKS_SMTP_USER` — 발신 메일 (예: `jsh38@hnkkorea.com`)
- `HIWORKS_SMTP_PASS` — **메일 전용 비밀번호** (특수문자 `#` 있으면 `"..."` 로 감싸기)
- `TARGET_EMAIL` — 수신 메일

### 1-7. 수동 실행 테스트

```powershell
.\scripts\run_rss_mailer.ps1
```

- `발송 완료: ... (메일 1통)` 또는 `신규 기사 없음 — 발송 생략` → **성공**
- `535` / `Access denied` → 하이웍스 POP3/SMTP·메일 전용 비밀번호·허용 국가(대한민국) 재확인

인증만 따로 보려면:

```powershell
.\.venv\Scripts\python src\check_mail_auth.py
```

`POP3 로그인: OK` / `SMTP 로그인: OK` 가 나와야 합니다.

## 2단계: 작업 스케줄러 열기

1. 키보드 **Win + R**
2. `taskschd.msc` 입력 → **확인**
3. **작업 스케줄러** 창이 열립니다.

---

## 3단계: 새 작업 만들기

1. 오른쪽 **「작업 만들기…」** 클릭  
   (「기본 작업 만들기」가 아닌 **「작업 만들기」**)

---

## 4단계: 「일반」 탭

| 항목 | 설정 |
|------|------|
| 이름 | `Boannews RSS Hiworks Mail` (원하는 이름 가능) |
| 설명 | `Boannews RSS digest 1일 1회` |
| 보안 옵션 | **사용자의 로그온 여부에 관계없이 실행** 체크 |
| | **가장 높은 수준의 권한으로 실행** 체크 (권한 오류 시) |
| 구성 대상 | Windows 10/Windows Server 2016 이상 |

**사용자 또는 그룹:** 이 PC/서버에 로그온 가능한 계정 (프로젝트 폴더 읽기·쓰기 가능한 계정).

**확인**은 아직 누르지 말고 다음 탭으로 이동합니다.

---

## 5단계: 「트리거」 탭

1. **「새로 만들기…」** 클릭
2. 설정:

| 항목 | 설정 |
|------|------|
| 작업 시작 | **일정에 따라** |
| 설정 | **매일** |
| 시작 | 원하는 **날짜** + **시간** (예: 오전 **08:30:00**) |
| 사용 | **사용** 체크 |

3. **「확인」**

> **매일 같은 시각 1회**가 목표입니다.  
> 나중에 **매시 정각**으로 바꾸려면: 트리거 편집 → **고급 설정** → **작업 반복 간격** `1시간`, **기간** `무기한`.

---

## 6단계: 「동작」 탭

1. **「새로 만들기…」** 클릭
2. 설정:

| 항목 | 값 |
|------|-----|
| 동작 | **프로그램 시작** |
| 프로그램/스크립트 | `powershell.exe` |
| 인수 추가(옵션) | 아래 한 줄 전체 (경로 수정) |

**인수 추가** (복사 후 `D:\develop\hiworks-Ctrl` 만 본인 경로로 변경):

```
-NoProfile -ExecutionPolicy Bypass -File "D:\develop\hiworks-Ctrl\scripts\run_rss_mailer.ps1"
```

| 항목 | 값 |
|------|-----|
| 시작 위치(옵션) | `D:\develop\hiworks-Ctrl` |

3. **「확인」**

---

## 7단계: 「조건」 탭

- 노트북이 아니면 **「컴퓨터의 AC 전원일 때만…」** 체크 **해제**해도 됩니다.
- 그 외는 기본값 유지.

---

## 8단계: 「설정」 탭

권장:

| 항목 | 설정 |
|------|------|
| 작업이 실행 중이면 | **새 인스턴스 시작 안 함** (메일 중복 방지) |
| 작업 실행 시간 제한 | 필요 시 **1시간** (기본 3일이면 그대로도 무방) |

---

## 9단계: 저장

1. **「확인」** 클릭
2. **「사용자의 로그온 여부에 관계없이 실행」** 을 썼다면 **계정 비밀번호** 입력 요청 → 해당 계정 비밀번호 입력

작업 스케줄러 **「작업 스케줄러 라이브러리」** 목록에 `Boannews RSS Hiworks Mail` 이 보이면 등록 완료입니다.

---

## 10단계: 스케줄러에서 바로 테스트

1. 목록에서 **Boannews RSS Hiworks Mail** 우클릭
2. **「실행」** 클릭
3. 아래쪽 **「기록」** 탭 선택 (기록이 꺼져 있으면 우클릭 → **「모든 작업 기록 사용」**)
4. **작업이 시작됨** → **작업이 완료됨** (결과 코드 **0**) 확인
5. 하이웍스 메일함에서 `[보안뉴스]` 메일 또는 (신규 없으면) 발송 없음 확인

---

## 11단계: 운영 시 주의

1. **한 곳에서만** 스케줄 등록 (개발 PC + 서버 **동시** 실행 금지 → `published_history.txt` 충돌).
2. **`published_history.txt`** 는 프로젝트 루트에 자동 생성·갱신됩니다. 백업/이전 시 함께 옮기세요.
3. 비밀번호 변경 시 **`.env`만** 수정하면 됩니다 (작업 스케줄러 재등록 불필요).
4. GitHub Actions **schedule** 은 끄거나 워크플로 비활성화해 **이중 실행**을 막으세요.

---

## 자주 나는 문제

| 증상 | 확인 |
|------|------|
| 결과 코드 **1** | PowerShell에서 `.\scripts\run_rss_mailer.ps1` 직접 실행해 오류 메시지 확인 |
| `.venv` 없음 | 1단계 1-4 ~ 1-5 다시 실행 |
| SMTP 535 | `python src\check_mail_auth.py` → POP3/SMTP·메일 전용 비밀번호 |
| 작업은 성공인데 메일 없음 | `신규 기사 없음` 이면 정상; 테스트 시 `published_history.txt` 일부 삭제 후 재실행 |
| PowerShell 실행 정책 | 인수에 `-ExecutionPolicy Bypass` 포함 (6단계) |

---

## 요약

```
매일 08:30 (예)
  → taskschd.msc
  → 작업 만들기
  → 트리거: 매일
  → 동작: powershell.exe -File "...\scripts\run_rss_mailer.ps1"
  → 우클릭 「실행」으로 테스트
```

게시판 자동 등록(메일 규칙)은 하이웍스 웹메일에서 **별도 1회** 설정하면 됩니다.
